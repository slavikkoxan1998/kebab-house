# JOURNAL — kebab-house

## 2026-08-02 17:38

Додано демо-фічу для показу клієнту: AI-асистент для збору замовлень (плаваючий чат-віджет 💬 внизу праворуч, стилізований під тему сайту).

- `assistant-server/server.js` — легкий Node.js HTTP-сервер без зовнішніх залежностей: віддає сам сайт (`index.html`, `images/`) і ендпоінт `POST /chat`, який проксить історію діалогу в Gemini API (`gemini-flash-latest`) із системним промптом, що містить повне меню (23 позиції) і інструкції вести діалог чеською, порахувати суму і в кінці попросити ім'я + час видачі.
- Ключ (`GEMINI_KEY`) лежить у `assistant-server/.env` (у `.gitignore`, не в git).
- **Важливо: нічого нікуди не записується** — ні в базу, ні в Telegram, ні в файл. Сервер лише проксить репліки в Gemini і повертає відповідь, за задумом користувача (демо, не продакшн).
- Меню в index.html лишилось без змін (js-масив `menuData`), система промпту дублює його вручну текстом — якщо мінятиметься меню на сайті, треба синхронізувати і `SYSTEM_PROMPT` у `server.js`.
- **Ключі Gemini**: перший ключ зі Script Properties `кебаб лідген` Apps Script (`GEMINI_KEY`) має спільний денний ліміт 20 запитів на модель `gemini-3.6-flash` (безкоштовний тариф) — вичерпався під час тестування. Користувач дав кілька додаткових ключів, робочим виявився `AQ.Ab8RN6KC...` (інший проєкт, не вичерпаний) — саме він зараз у `.env`. Інші моделі (`gemini-2.0-flash` тощо) на цих проєктах мають ліміт 0 — недоступні без білінгу.
- Перевірено наскрізно через Playwright: повна розмова (2× döner kebab klasik + malý talíř s hranolky, без соусу) → бот порахував суму правильно (445 Kč), запитав ім'я і час, дав фінальне зведення.
- Запуск сервера: `cd assistant-server && node server.js` (порт 8790) — **важливо запускати через інструментальний background-режим, не вручну через `nohup`/`disown`**, інакше лишається старий процес зі старим `.env`/кодом (той самий баг, що вже описаний у `cms/JOURNAL.md` для `dev:canvas`).
- Поки що **лише локально**, нічого не запушено в GitHub — чекаю рішення користувача.
